# 🗺️ Роадмап: Веб-сайт государственных испытательных автолабораторий КР

> **Заказчик:** ГП «Институт допуска к дорожному движению» при ГЦ по регистрации ТС и ВС
> **Цель:** Единая информационная платформа для взаимодействия с гражданами и юрлицами

---

## 🧱 Технологический стек (обоснование)

| Уровень            | Технология              | Почему выбрана                                              |
|--------------------|--------------------------|------------------------------------------------------------|
| **Веб-фреймворк**  | **Next.js 14+** (App Router) | SSR/SSG для быстрой загрузки, серверные компоненты (RSC), SEO из коробки, file-based routing. Стандарт де-факто для современных гос. сайтов и сайтов-визиток с админкой.                    |
| **Типизация**      | **TypeScript**           | Безопасность кода, отличный autocomplete, меньше багов на проде. Обязателен для гос. систем.                                        |
| **Стилизация**     | **Tailwind CSS 3.4+** + **shadcn/ui** | Утилитарный CSS с компонентами, быстрое прототипирование, адаптив из коробки. shadcn/ui даёт доступные (a11y) готовые UI-компоненты. |
| **Иконки**         | **lucide-react**          | SVG-иконки из той же экосистемы, что и shadcn/ui. 1000+ иконок, tree-shakable, типизированные, 1.5kB на иконку. Полная совместимость с Tailwind (цвета, размеры, hover). |
| **CMS/Бэкенд**     | **Payload CMS 3.0**      | Headless CMS с админ-панелью, работает внутри Next.js. Управление страницами, новостями, документами, филиалами без отдельного бэкенда. MongoDB/Postgres. |
| **База данных**    | **PostgreSQL** (через Vercel Postgres / Neon / Supabase) | Надёжная и стабильная. Payload CMS работает с Postgres из коробки (Drizzle ORM). |
| **Хранение файлов**| **Vercel Blob / MinIO (S3)** | Для хранения нормативных документов (PDF, DOCX, XLSX), изображений новостей. MinIO — бесплатный self-hosted S3 (для VPS). |
| **Хостинг**        | **Vercel** / **Docker на VPS** | Vercel для быстрого деплоя и preview-веток. Docker Compose для state-размещения, если нужен полный контроль. |
| **Карты**          | **Leaflet** (react-leaflet) | Бесплатная альтернатива Google Maps, работает с OpenStreetMap — идеально для странового покрытия КР.                                 |
| **Поиск**          | **Pagefind** / **Algolia** | Pagefind — бесплатный статический поиск без сервера. Algolia — если нужен мощный документ-поиск.                                     |
| **Языки**          | **next-intl**            | Лучший i18n-роутер для Next.js App Router. Кыргызский, русский, английский.                                                         |
| **Интерактив**     | **framer-motion**        | Анимации и микровзаимодействия (появление секций при скролле, плавные переходы, hover-эффекты на карточках).                         |
| **Формы**          | **react-hook-form** + **zod** | Валидация форм, типизированные схемы, минимум зависимостей.                                                                         |
| **Спам-защита**    | **Turnstile** (Cloudflare) | Бесплатная, невидимая капча.                                                                                                         |

### Альтернативный стек (если нужно проще/быстрее):

| Уровень | Альтернатива |
|---------|--------------|
| Веб-фреймворк | **Nuxt 3** (Vue) с Nuxt Content — проще для команды без React-опыта |
| CMS | **Strapi** (headless CMS с админкой из коробки) |
| База данных | **PostgreSQL** (Strapi) |
| Хостинг | Docker на VPS или ArvanCloud (локальный облачный КР) |

> **Рекомендация:** Основной стек (Next.js + Payload CMS) — актуальный, стабильный, один фреймворк на всё, минимум движущихся частей.
